Sobre

O Curso • INFONET

O curso de Informática para Internet prepara os alunos para desenvolver e criar soluções voltadas ao ambiente digital. Ao longo da formação, são trabalhados conhecimentos de programação, desenvolvimento de sites, banco de dados, design e outras tecnologias utilizadas na construção de aplicações para a internet.
Mais do que aprender ferramentas, o curso estimula a criatividade, a lógica e a capacidade de transformar ideias em projetos funcionais. É nesse processo que tecnologia e criação se encontram, dando aos alunos a oportunidade de desenvolver projetos como esta própria galeria.

Código

HTML, CSS & JavaScript

Foram a base da construção do site. O HTML estruturou todo o conteúdo, enquanto o CSS definiu a identidade visual, os detalhes e as animações. Já o JavaScript foi utilizado para criar interações e tornar a experiência mais dinâmica.

Bootstrap

Foi utilizado para auxiliar na estrutura e na responsividade do site. Seus componentes e classes facilitaram a criação de elementos como a navbar, os cards, os modais e o sistema de grid, garantindo uma adaptação adequada a diferentes telas.

Photoshop

Foi utilizado na criação e edição das imagens presentes na galeria. Por meio de filtros, ajustes, efeitos e manipulações, algumas imagens foram transformadas para explorar diferentes estilos artísticos e composições visuais.

Ferramentas de Apoio

Foram utilizadas como ferramentas de apoio durante o processo criativo e de desenvolvimento. Auxiliaram na geração de ideias, na resolução de dúvidas, na criação de referências e no aprimoramento de elementos visuais e textuais do projeto.
